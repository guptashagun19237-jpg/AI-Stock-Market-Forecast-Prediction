# 📈 AI Stock Market Forecast Prediction

An interactive Stock Market Analysis and Prediction web application built using Python, Streamlit, Machine Learning, Plotly and Yahoo Finance API.

---

## 🚀 Features

- Live Stock Price Analysis
- Company Information
- Historical Stock Data
- Moving Average (50 & 200 Days)
- Candlestick Chart
- Trading Volume Analysis
- Download Historical Data
- Daily Return Analysis
- Machine Learning Stock Price Prediction
- Tomorrow Stock Price Prediction
- Model Performance Metrics (MAE, RMSE, R² Score)

---

## 🛠 Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- yfinance
- Scikit-learn
- Joblib

## ▶️ Run Locally

Clone the repository

```bash
git clone https://github.com/guptashagun19237-jpg/AI-Stock-Market-Forecast-Prediction.git
```

Go to folder

```bash
cd AI-Stock-Market-Forecast-Prediction
```

Install libraries

```bash
pip install -r requirements.txt
```

Run

```bash
streamlit run app.py
```
